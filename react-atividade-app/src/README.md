
# Minha Primeira Aplicação React

## Sobre o projeto

Esta é minha primeira aplicação desenvolvida com React e Vite.

O projeto utiliza componentes funcionais e props para organizar e reutilizar códigos.

## Componentes utilizados

- Header: apresenta o título da aplicação.
- Footer: apresenta o rodapé.
- Card: recebe informações através de props.
- Lista: apresenta uma lista utilizando o método map().
- App: reúne todos os componentes.

## Reflexão

### Diferença entre abordagem imperativa e declarativa

Na abordagem imperativa, utilizamos JavaScript para informar passo a passo como os elementos devem ser criados e modificados no HTML.

Na abordagem declarativa, utilizada pelo React, informamos como queremos que a interface apareça, e o React cuida das atualizações necessárias.

### Por que o Virtual DOM otimiza a performance?

O Virtual DOM é uma representação virtual da estrutura da página. O React compara as mudanças entre essa representação e a anterior, atualizando no DOM real apenas as partes necessárias. Isso evita atualizações desnecessárias e pode melhorar a performance da aplicação.
